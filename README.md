# oasis2-longitudinal-trajectory
A two-stage machine learning pipeline implementing leak-proof subject-level validation to predict longitudinal neurodegeneration trajectories from baseline MRI scans using the OASIS-2 dataset.

## Installation

Create and activate a virtual environment, then install the project and its
development tools:

```shell
python -m venv .venv
python -m pip install -e ".[dev]"
```
